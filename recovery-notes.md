# Заметки о восстановлении

## Что восстановлено из истории Git
Абзац с исходными допущениями Budget.md вернул командой
git restore --source=HEAD~1 -- Budget.md
после просмотра старой версии через git show HEAD~1:Budget.md.
Актуальный расчёт возвращён осмысленной правкой и новым коммитом.

## Что восстановлено из резервной копии
Вложение, не добавленное в историю Git: резервная копия всей учебной
папки содержит его целиком. Копия открыта как отдельное хранилище,
заметка и вложение проверены.

## Вывод
Git возвращает зафиксированные версии файлов; резервная копия нужна
для материалов, которые ещё не попали в историю.
