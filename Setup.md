# Настройка обмена изменениями

## Рассмотренные клиенты
FIT — плагин Obsidian для обмена файлами через GitHub, статус beta,
конфликтные версии сохраняются в папке _fit.
GitSync — отдельный мобильный Git-клиент, работает с папкой репозитория.

## Выбранный способ
Обмен проверен между двумя отдельными локальными копиями репозитория
на настольном компьютере (Git + плагин Obsidian Git). Мобильный клиент
не использовался; поддержка платформ и инструкции FIT и GitSync изучены
по документации авторов.

## Порядок обмена
1. В основной копии: правка строки, коммит, push.
2. Во второй копии: pull --ff-only до редактирования.
3. Во второй копии: добавление другой строки, коммит, push.
4. В основной копии: pull --ff-only и проверка получения.
